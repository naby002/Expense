# Expense tracker

A React and Vite expense tracker with category filtering, validation, totals, and deletion.

## Getting started

```sh
npm install
npm run dev
```

## Checks

```sh
npm run test:run
npx vitest run --coverage
npm run lint
npm run build
```

For end-to-end tests, start `npm run dev` in one terminal and run `npm run cy:run` in another. Use `npm run cy:open` for the interactive Cypress runner.
